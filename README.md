# Modern Personal Portfolio (Next.js 15 + TypeScript + Tailwind CSS)

Ultra-premium, high-performance portfolio frontend engineered with Next.js 15, React 19, TypeScript, and Tailwind CSS. Connects to the separate Node.js Express backend.

## Features
- **Next.js 15 App Router**: Server-side pre-rendering with resilient client fallbacks.
- **Glassmorphic Design**: Curated dark palette, glowing accents, and particle mesh background.
- **Interactive Projects Showcase**: Real-time category filtering, metrics callouts, and detailed modal views.
- **Dynamic Skills Matrix**: Interactive category switcher and percentage proficiency bars.
- **Experience Timeline**: Career history with key architectural achievements.
- **Live Contact Gateway**: Connected directly to the separate Node.js API with input validation and instant feedback.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run in Development
```bash
npm run dev
```
Runs on `http://localhost:3000`.

### 3. Build for Production
```bash
npm run build
npm start
```
